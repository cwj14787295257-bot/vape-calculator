# Make My Vape · 电子烟液配比计算台

采用 [MakeMyVape Calculator](https://makemyvape.co.uk/pages/calculator) 物理计算逻辑的纯前端工具，支持深色与浅色自适应外观，提供成分体积、克重与滴数换算，数据保存在本地浏览器。

---

## 功能说明

1. **计算规则**：
   - **VG (植物甘油) 密度**：1.26 g/ml。
   - **PG (丙二醇) 密度**：1.00 g/ml。
   - **稀释剂**：1.00 g/ml。
   - **滴数换算**：20 滴 = 1 ml。
   - **基底平衡检验**：分别统计香精与尼古丁中包含的 PG 与 VG，扣减后计算需补充的纯 PG 与 VG。若原料自带的基质超出目标比例，界面提示调整参数。
2. **界面与外观**：
   - 采用网格卡片布局与 48px 毛玻璃置顶导航栏。
   - 随操作系统的深色或浅色模式自动切换配色。
3. **本地存储**：
   - 使用浏览器 LocalStorage 保存配方数据，不依赖后端数据库。
   - 支持保存当前配方、载入历史配方与删除配方。
4. **导出与打印**：
   - **图片导出**：调用 html2canvas 生成调配清单图片（PNG）。
   - **调配台打印**：提供打印样式表，直接调用系统打印。

1. **《电子烟管理办法》第二十六条**：禁止销售除烟草口味外的调味电子烟和可自行添加雾化物的电子烟（开放式/注油式）。

3. **《电子烟强制性国家标准》(GB 41700-2022)**：烟液中的烟碱浓度不得高于 20 mg/g（约 20 mg/ml），烟碱总量不得高于 200 mg，添加剂需符合允许使用物质目录。

## 使用方式

在文件管理器中找到 `index.html`，双击即可在浏览器中打开使用。

如需局域网查看，可在当前目录启动静态服务：
```bash
python3 -m http.server 8080
```
浏览器访问 `http://localhost:8080`。

## 计算公式

$$\text{有效调配总量 } V_{\text{base}} = V_{\text{total}} \times (1 - \text{ExtraDiluent\%})$$

$$\text{尼古丁添加量 } V_{\text{nic}} = V_{\text{base}} \times \frac{\text{DesiredStrength}}{\text{BaseStrength}}$$

$$V_{\text{pure\_pg}} = V_{\text{base}} \times \text{PG\%} - (V_{\text{flavours\_pg}} + V_{\text{nic\_pg}})$$

$$V_{\text{pure\_vg}} = V_{\text{base}} \times \text{VG\%} - (V_{\text{flavours\_vg}} + V_{\text{nic\_vg}})$$

$$\text{成分克重 } (\text{g}) = \text{体积 } (\text{ml}) \times \text{比重 } (\text{g/ml})$$
